# Atajos

Para imprimir y tener al lado de la computadora.

| Tecla | Qué hace |
| --- | --- |
| `Espacio`, `→`, `Enter`, `Av Pág` (clicker) | Siguiente paso. Durante una animación, la termina. Clic en el tablero hace lo mismo |
| `←`, `Re Pág`, `Retroceso` | Volver un paso (sin animación) |
| `1` `2` `3` | En la bifurcación: negociar, leer, aceptar sin leer |
| `V` | Vista general del tablero |
| `F` | Pantalla completa |
| `M` o `G` | Menú: ir a cualquier momento, ajustes (nombre, calidad, sonido), empezar de cero. También con el botón redondo abajo a la derecha |
| `Esc` | Cerrar el menú o el aviso de "Continuar" |

El sonido se prende y se apaga con el botón del parlante (arriba a la derecha) o en el menú.

## Qué pasa con cada `Espacio`

### La vuelta

| Momento | `Espacio` |
| --- | --- |
| Antes de girar | Gira la ruedita, el auto avanza casilla por casilla y se abre la diapositiva con el título |
| Título | Aparece el texto (en las casillas 5, 8 y 13, la primera parte) |
| Texto | Siguiente parte, o se cierra la diapositiva |
| Después de la casilla 14 | Gira la ruedita y el auto llega a Destino: "¡Llegamos sanos y salvos!" |
| Destino | Aparece el celular |

### El juego

| Momento | `Espacio` |
| --- | --- |
| Celular | Toca ACEPTAR, "¡Viaje confirmado!", aparecen los autos en la bifurcación |
| Bifurcación | No hace nada: elegir con `1` `2` `3` o clic, auto por auto |
| Turno, antes de girar | Gira la ruedita |
| Ruedita girada | El auto avanza a su casilla, con su animación |
| Auto en la casilla | Se abre la tarjeta: situación y pregunta |
| Tarjeta | Se da vuelta: la respuesta |
| Respuesta | Se cierra y pasa al turno siguiente |
| Última vuelta, antes de girar | Gira la ruedita |
| Ruedita girada | El auto llega a Destino y se da vuelta su sentencia |
| Sentencia | Se cierra y pasa al auto siguiente; en la cuarta, a la ruedita (con fanfarria y papel picado) |

### Final

| Momento | `Espacio` |
| --- | --- |
| Ruedita | Cartel "¿Se dieron cuenta…?"; con otro `Espacio`, todos los números que salieron |
| Celular final | Clic en la letra chica: las cláusulas del juego |

## Si algo sale mal

- Se pasó un paso de más: `←`.
- Hay que repetir una parte o saltear: `M` > "Ir a" y elegir el momento.
- El navegador se cerró: abrir `JUGAR.html` de nuevo y "Continuar".
- Va lento: `M` > Calidad gráfica Media o Baja (recarga la página y sigue donde estaba).
- No suena: el botón del parlante, o subir el volumen en `M`. Algunos navegadores esperan el primer clic o tecla.
