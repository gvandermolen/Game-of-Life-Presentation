# Atajos para los expositores

Imprimir y tener a mano durante la presentación.

## Jugar

| Tecla | Acción |
| --- | --- |
| `Espacio` · `→` · `AvPág` · `Enter` | Comenzar, girar la ruleta, acelerar una animación, cerrar la pantalla de ganador |
| `A` `B` `C` `D` o `1` `2` `3` `4` | Marcar la opción que eligió el equipo |
| `S` | Respuesta correcta |
| `N` | Respuesta incorrecta |
| `X` | Anular la carta (sin efecto) |
| `1` … `6` en un choque | Prevalece el equipo 1, 2, … (orden de la carta) |
| `0` en un choque | Sin responsable |

Los clickers de diapositivas envían `→` o `AvPág`: sirven para girar y avanzar. Los veredictos siempre se dan con teclado o clic, para no marcar una respuesta por accidente.

## Corregir

| Tecla | Acción |
| --- | --- |
| `Z` | Deshacer la última acción |
| `Shift` + `Z` o `Y` | Rehacer |
| `C` | Configuración: historial, ir a la jugada N, ajuste manual, reiniciar |
| `Esc` | Cerrar configuración |

## Pantalla

| Tecla | Acción |
| --- | --- |
| `F` | Pantalla completa |
| `V` | Vista general del tablero |
| `1` … `6` | Seguir a un equipo con la cámara (fuera de cartas) |
| `L` | Mostrar u ocultar la leyenda |
| `M` | Silenciar |

## Si algo sale mal

- **Se giró por error**: `Z`.
- **Se marcó mal una respuesta**: `Z` vuelve a abrir la carta.
- **Hay que volver varias jugadas**: `C` > Partida > Historial > "Ir aquí".
- **Una ficha quedó en otro lado** (por ejemplo, lo decidió el profesor): `C` > Partida > Ajuste manual > casilla > Mover.
- **Le toca a otro equipo**: `C` > Partida > Ajuste manual > Dar turno.
- **Se cerró el navegador**: abrir de nuevo `JUGAR.html` y "Continuar partida".
- **Va lento**: `C` > Presentación > Calidad gráfica > Media o Baja.
