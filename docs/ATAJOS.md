# Atajos

Para imprimir y tener al lado de la computadora.

| Tecla | Qué hace |
| --- | --- |
| `Espacio`, `→`, `Enter`, `Av Pág` (clicker) | Siguiente paso. Durante una animación, la termina. Clic en el tablero hace lo mismo |
| `←`, `Re Pág`, `Retroceso` | Volver un paso (sin animación) |
| `1` `2` `3` | En la bifurcación: negociar, leer, aceptar sin leer |
| `V` | Vista general del tablero |
| `M` | Sonido sí / no |
| `F` | Pantalla completa |
| `G` | Menú: ir a cualquier momento, ajustes, empezar de cero |
| `Esc` | Cerrar el menú o el aviso de "Continuar" |

## Qué pasa con cada `Espacio`

| Momento | `Espacio` |
| --- | --- |
| Cartel "Terminó la clase…" | Aparece el celular |
| Celular | Toca ACEPTAR, "¡Viaje confirmado!", aparecen los autos en la bifurcación |
| Bifurcación | No hace nada: elegir con `1` `2` `3` o clic |
| Turno, antes de girar | Gira la ruedita, el auto avanza, se abre la carta |
| Carta | Se da vuelta y muestra la respuesta |
| Respuesta | Pasa al turno siguiente |
| Después del turno 16 | Los autos llegan a Casa |
| Sentencias | Se da vuelta una sentencia por vez (4) |
| Ruedita | Cartel "¿Se dieron cuenta…?" |
| Celular final | Clic en la letra chica: las cláusulas del juego |

## Si algo sale mal

- Se pasó un paso de más: `←`.
- Hay que repetir una parte o saltear: `G` > "Ir a" y elegir el momento.
- El navegador se cerró: abrir `JUGAR.html` de nuevo y "Continuar".
- Va lento: `G` > Calidad gráfica Media o Baja (recarga la página y sigue donde estaba).
- No suena: `M`, o subir el volumen en `G`. Algunos navegadores esperan el primer clic o tecla.
